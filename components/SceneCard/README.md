# SceneCard

Scene cards list a script's scenes for navigation and coverage at a glance.

**Anatomy:** scene number (Courier) · scene heading (`scene-heading`, uppercase) · one-line synopsis · metadata: page length (eighths), characters, frame coverage · side slot for Changed or a status.

**States:** default, hover (`border-strong`), selected (`bg-selected` + `border-selected`), changed (`l-asset__changed`). Drag to reorder only in Cine Scribe; elsewhere order follows the script.

**Don't:** show more than one line of synopsis; recolour cards by status.
