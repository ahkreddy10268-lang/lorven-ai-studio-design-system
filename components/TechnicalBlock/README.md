# TechnicalBlock

Technical blocks show structured, machine-shaped data — shot metadata, export settings, IDs — in Geist Mono on `bg-code`.

**Variants:** key–value (`l-code l-kv`) for shot and file data; preformatted (`pre.l-code`) for settings or logs, with three token colours only (`t-muted`, `t-key`, `t-str`).

**Rules:** use for data people copy or compare exactly, not for prose. Keep lines short; scroll horizontally rather than wrap configuration. Provide a Copy action when the content is meant to be pasted elsewhere.

**Don't:** use monospace for screenplay text (Courier Prime) or for interface copy.
