# VersionReference

A version reference states what an asset was built from and whether that is still current.

**Variants:** current (`l-verref`, `current` icon, secondary text) · check (`l-verref--check`, `check-source` icon) · outdated (`l-verref--outdated`, `outdated` icon). Each includes the source name and version in bold and, when not current, a link to see or review the change.

**Content:** "Built from **Screenplay v6** · v7 changed 2 linked scenes · Review". Count what changed when known; otherwise "v7 is available".

**Don't:** say "out of sync" or "synced" — Lorven does not claim live sync. Don't use this for approval.
