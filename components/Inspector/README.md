# Inspector

The inspector is the right-hand panel that shows and edits properties of the one selected item — a frame, scene, shot or asset.

**Anatomy:** title (the item's name) and close · sections with eyebrow headings (Shot, References, Source) · property rows (label column 96px, control or value) · reference chips (`character`, `location`, `script` icons) · source and provenance.

**Behaviour:** opens on selection, width 300px (resizable 280–420), never covers the canvas below `bp-wide` — it becomes a bottom sheet at compact widths. Edits save on blur with an inline "Saved" confirmation; values set by generation keep their provenance until a person edits them.

**Don't:** put multi-step workflows here (use the review surface); show empty sections.
