# SegmentedControl

A segmented control switches between 2–4 views or modes of the same content.

**Use:** view switching (Script / Board / Shots), density (Comfortable / Compact). The selected segment sits on `bg-surface` inside a `bg-recessed` track.

**Behaviour:** `role="radiogroup"`; arrow keys move and select. Icons optional, labels required.

**Don't:** use it for navigation between pages (tabs), or for actions.
